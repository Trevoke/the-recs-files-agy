# the-recs-files-agy

The [recs files](https://github.com/Trevoke/the-recs-files) packaged for Antigravity: the skills and the `recs-code-reviewer` subagent, version 1.0.0-beta.

This repository is generated from https://github.com/Trevoke/the-recs-files on each release. Open issues and
pull requests there; changes made here are overwritten.

## Install

```sh
agy plugin install https://github.com/Trevoke/the-recs-files-agy
```

Then open a project and ask for `recs-kickstart`.
